# 전자기 유도로 에너지 하베스팅!

중학교 3학년 과학 · 에너지 전환과 보존 — 전자기 유도를 이용한 에너지 하베스팅 수업 슬라이드 (45분 × 2차시, 38장)

**바로 보기:** https://hohohoon01.github.io/energy-harvesting/

## 사용법
| 동작 | 키 |
|---|---|
| 다음 / 숨은 정답 보이기 | → · 스페이스 · 클릭 |
| 이전 | ← · 화면 왼쪽 클릭 |
| 발표자 노트 | N |
| 전체 화면 | F |
| 특정 슬라이드로 이동 | 주소 끝에 `#번호` (예: `#14`) |

## 구성
- 1차시: 에너지 하베스팅 도입 → 탐구 1 (코일·자석·검류계) → 탐구 2 (손 발전 후레쉬) → 정리
- 2차시: 손발전기 만들기 → 원리 → 생활 속 사례 → 아이디어 고안 → 자이로드롭 자석 브레이크 → 영상 → 퀴즈
